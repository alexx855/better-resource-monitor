# Política de Privacidade

**Última atualização: Janeiro de 2026**

## Visão geral

O Better Resource Monitor ("o Aplicativo") é um aplicativo de desktop que exibe informações de recursos do sistema na sua barra de menus. Esta política de privacidade explica como lidamos com seus dados.

## Coleta de dados

**Nós não coletamos nenhum dado pessoal.**

O Aplicativo opera inteiramente localmente no seu dispositivo. Todas as informações do sistema (uso de CPU, uso de memória, uso de armazenamento, atividade de rede, estatísticas de GPU) são:
- Lidas diretamente do seu sistema operacional
- Exibidas apenas na sua tela local
- Nunca transmitidas para servidores externos
- Nunca armazenadas em nenhum banco de dados externo

O uso de armazenamento é calculado pela capacidade total e livre informada pelo sistema operacional para o volume principal do usuário. O Aplicativo não lê nomes de arquivos, conteúdos de arquivos, volumes externos nem detalhes por volume.

## Armazenamento de dados

O Aplicativo armazena apenas suas preferências (como quais métricas exibir e configurações de aparência) localmente no seu dispositivo usando o armazenamento de configuração padrão do seu sistema operacional. Esses dados nunca saem do seu computador.

## Serviços de terceiros

O Aplicativo não:
- Usa serviços de analytics
- Inclui publicidade
- Conecta-se a APIs externas
- Compartilha dados com terceiros

## Acesso à rede

O Aplicativo monitora sua atividade de rede para exibir velocidades de upload/download. Ele não:
- Faz nenhuma solicitação de rede de saída
- Envia nenhum dado pela internet
- Acessa o conteúdo do seu tráfego de rede

## Código aberto

O Better Resource Monitor é um software de código aberto. Você pode revisar o código-fonte completo no [GitHub](https://github.com/alexx855/better-resource-monitor) para verificar essas práticas de privacidade.
