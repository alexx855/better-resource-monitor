# Política de privacidad

**Última actualización: enero de 2026**

## Descripción general

Better Resource Monitor ("la Aplicación") es una aplicación de escritorio que muestra información de recursos del sistema en tu barra de menús. Esta política de privacidad explica cómo manejamos tus datos.

## Recopilación de datos

**No recopilamos ningún dato personal.**

La Aplicación opera completamente de forma local en tu dispositivo. Toda la información del sistema (uso de CPU, uso de memoria, actividad de red, estadísticas de GPU) es:
- Leída directamente desde tu sistema operativo
- Mostrada solo en tu pantalla local
- Nunca transmitida a servidores externos
- Nunca almacenada en ninguna base de datos externa

## Almacenamiento de datos

La Aplicación almacena solo tus preferencias (como qué métricas mostrar y configuraciones de apariencia) localmente en tu dispositivo utilizando el almacenamiento de configuración estándar de tu sistema operativo. Estos datos nunca salen de tu computadora.

## Servicios de terceros

La Aplicación no:
- Utiliza servicios de analíticas
- Incluye publicidad
- Se conecta a APIs externas
- Comparte datos con terceros

## Acceso a la red

La Aplicación monitorea tu actividad de red para mostrar las velocidades de carga/descarga. No:
- Realiza ninguna solicitud de red saliente
- Envía ningún dato a través de internet
- Accede al contenido de tu tráfico de red

## Código abierto

Better Resource Monitor es software de código abierto. Puedes revisar el código fuente completo en [GitHub](https://github.com/alexx855/better-resource-monitor) para verificar estas prácticas de privacidad.

## Cambios en esta política

Si realizamos cambios en esta política de privacidad, actualizaremos la fecha de "Última actualización" anterior.
