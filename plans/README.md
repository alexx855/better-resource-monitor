## Direction Findings (maintainer options, not ranked against bugs)

- **Decide the Linux fork.** `docs/roadmap.md:15` explicitly asks for the
  decision; the repo carries Linux autostart/theme/NVML code, `.deb`/AppImage
  bundle config, and generated Ubuntu badges — while `agent-facts.json` says
  platforms: macOS only. Productize (CI matrix + release artifacts, coarse L)
  or formally demote and strip the Ubuntu scaffolding (S–M).
- **Single source of truth for distribution facts.** `llms.txt`,
  `agent-facts.json`, README badges, and FAQ copy disagree about install paths
  today. A small manifest consumed by the site build (S–M) would keep plan
  006's outcome from drifting again.
- **Tray tuning as a user-facing feature.** Refresh interval is an
  undocumented env var (`SILICON_UPDATE_INTERVAL`); alert threshold is
  hardcoded at 81.0 (`tray_render.rs:15`), while `examples/render_tray_icon.rs`
  already exposes both as flags. Menu presets via the existing settings store
  are cheap (M); trade-off against the "<0.1% CPU" claim.
- **Sensor-depth boundary.** Comparison pages repeatedly route fan/thermal
  users to Stats/iStat — a groomed backlog in marketing copy. Either formalize
  "permanently out of scope" on those pages or run a sandbox-feasibility spike
  (L, HIGH risk to the lightweight positioning).

## Findings Considered And Rejected

2026-07-08 audit:

- Network u64 counter overflow (`sum_network_totals`): summed totals would
  need ~18 exabytes to wrap; resets already handled by `saturating_sub`. Not real.
- Hot-plugged network interfaces "never appear": false — sysinfo 0.39.3
  `Networks::refresh(false)` inserts new interfaces (verified in crate source;
  the flag only controls removal of vanished ones).
- Removing the `wry` feature / WebKit weight from the tray-only app: Tauri v2
  has no non-wry desktop runtime; removal means leaving Tauri. Accepted cost.
- macOS process-lock fail-open on unexpected IO errors: defensible
  availability choice; duplicate detection (WouldBlock → exit) still works.
- sysinfo 0.39.3 → 0.39.5 bump: Dependabot territory, not a plan.
- CI running a full `pnpm tauri build` per PR: intentional (bundle-layout
  assertions); revisit only if CI minutes become a problem.
- Rust toolchain pinning (`rust-toolchain.toml`): low value while CI and local
  both track stable without issues.
- Empty `app-store` cargo feature: test-gating ceremony only; harmless, at
  most needs a comment.
- Pre-commit hooks / editorconfig: low value for the current contributor base;
  CI gates (plan 009) are the enforcement layer.
- Linux second-instance handler no-op: Linux is explicitly experimental
  (roadmap); fold into the Linux fork decision instead.

Carried from the 2026-06-11 audit (still valid):

- Tracked secret cleanup: `git ls-files` finds no tracked secret material;
  ignore rules cover p12/p8/env/provisioning profiles.
- Tauri capability referencing a `main` window that doesn't exist: low
  practical risk for a tray-only app with no webview.
