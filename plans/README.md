## Direction Findings

- Public distribution strategy should stay explicit. The code currently favors
  App Store/TestFlight distribution, while GitHub can remain source/provenance.
  If GitHub installers come back, that should be a deliberate release-system
  project, not copy drift.
- The website is becoming a real product surface, not just a README mirror:
  localized FAQs, comparison pages, image generation, machine-readable facts,
  and Search Console-driven copy all justify a first-class CI gate.
- Generated assets are now central to App Store and marketing surfaces. Keeping
  their inputs deterministic will make release closeout calmer.
