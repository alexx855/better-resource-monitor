# Security Policy

## Supported Versions

Security fixes are handled for the latest public release of Better Resource Monitor.

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability.

Email `hello@alexpedersen.dev` with:

- a short description of the issue,
- steps to reproduce,
- affected version or commit,
- any relevant logs, screenshots, or proof of concept.

Reports are reviewed as soon as practical. If the issue is confirmed, the fix and disclosure timing will be coordinated before public details are shared.
